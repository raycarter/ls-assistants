First Agent slice · review before execution

The injected-planner path supports approved read_file and web_fetch steps. Search and grep are unavailable. Planning runs no tools. A planner must be explicitly configured in the BFF; a production planner is not provided by this slice.

User requests, reviewed plans, approved source excerpts, tool results and logical model inputs/outputs recorded by this path are retained by the BFF, including fetched text for read-only inspection. This is not a complete LLM audit. Archive preserves this history; there is no automatic expiry. Permitted source text may contain sensitive content; this is not guaranteed secret-content scrubbing. Approved web_fetch requests contact the supplied URL and its redirects. Inspecting retained pages reads BFF storage without fetching again.
